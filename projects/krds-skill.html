/* overview */

AI를 쓰는 사람에서, AI의 도구를 만드는 사람으로

공공기관 웹 프로젝트는 KRDS(한국 디지털 정부 디자인 시스템) 준수가 사실상 표준이지만, AI 코딩 도구는 KRDS의 클래스 컨벤션과 접근성 규칙을 모릅니다. 매번 레퍼런스를 복붙하는 대신, AI가 KRDS를 '아는 상태'로 만드는 스킬 패키지를 직접 제작했습니다.

이 프로젝트는 제 커리어에서 의미가 큽니다 — AI 도구의 소비자에서 AI 도구의 제작자로 넘어간 전환점이기 때문입니다.

/* process */

제작 과정

01저장소 분석

KRDS 공식 GitHub 저장소를 클론해 구조를 전수 분석했습니다.

  • Actions·Forms·Navigation·Overlays·Feedback·Content·Layout 7개 카테고리, HTML 컴포넌트 74종
  • SCSS 디자인 토큰과 JavaScript 인터랙션 파일의 의존 관계 파악

02워크플로 정의

스킬이 처리할 4개 작업 유형을 정의했습니다.

  • 컴포넌트 HTML 생성 / 전체 페이지 레이아웃 조립 / 기존 HTML의 KRDS 리팩토링 / 접근성(WAI-ARIA) 감사·교정

03레퍼런스 자동 생성

74개 컴포넌트의 HTML 스니펫을 Python 스크립트로 순회·추출해 구조화된 레퍼런스 문서를 자동 생성했습니다.

  • 수작업 복사 대비 누락·오류 없이 일관된 문서 확보

04패키징

SKILL.md(설치·토큰·클래스 컨벤션·접근성 10원칙·워크플로·페이지 템플릿) + references/components.md 2파일 구성으로 .skill 패키지화했습니다.

  • 특정 프로젝트 종속 없는 범용 설계 — 어느 공공 프로젝트에서든 재사용 가능
