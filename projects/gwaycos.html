원료 데이터를 바이어의 언어로

Gwaycos는 천연색소 원료를 공급하는 B2B 기업입니다. 기존 제품 페이지는 카탈로그 PDF의 정보를 제대로 담지 못해, 바이어가 원료의 핵심 속성(용해도·발색·인증)을 한눈에 비교할 수 없었습니다.

10종 원료(Oleo 유용성 7종 + Aqua 수용성 3종)의 INCI명, 원료 식물, 농도별 발색 범위, 중국 NMPA 등록 여부, 안정성 시험 데이터를 PDF에서 추출·구조화한 뒤, 이 데이터 구조가 곧 UI 구조가 되도록 설계했습니다.

/* key-work */

설계 결정

01용해도 기반 탭 필터

바이어의 첫 질문은 '유용성인가 수용성인가' — 이 분류를 All/Oleo/Aqua 탭 필터로 최상단에 배치했습니다.

02농도별 컬러 스와치

0.1%에서 5.0%까지 농도에 따른 발색 변화를 그라디언트 스와치로 시각화 — 표 데이터로는 전달되지 않는 원료의 실제 가치를 보여줍니다.

03신뢰 배지 설계

NMPA(중국 인증) 등록과 안정성 시험 완료를 배지로 노출해, 수출 바이어의 핵심 검토 항목을 카드 레벨에서 즉시 확인하게 했습니다.

04프리미엄 뷰티 타이포

DM Serif Display + DM Sans 조합으로 '원료지만 뷰티 브랜드답게' — Clean Beauty 포지셔닝을 시각 언어로 번역했습니다.
