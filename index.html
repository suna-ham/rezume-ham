ABOUT

디자인에서 출발해 코드로, 다시 코드를 다루는 AI로. 매 단계에서 앞 단계의 감각을 버리지 않고 쌓아 올린 궤적입니다.

  1. UX/UI 디자인

    사용자의 의도와 화면의 구조를 설계하던 출발점. 디자인의 '왜'를 이해합니다.

  2. 웹 퍼블리싱

    HTML·CSS·JSP로 디자인을 픽셀 단위로 구현. 접근성과 마크업 품질에 집착합니다.

  3. 풀프로덕트 개발

    프런트엔드를 넘어 백엔드·DB·배포까지. 제품 전체의 흐름을 책임집니다.

  4. AI 에이전트 개발

    이제는 코드에게 일을 시키는 단계. LangGraph·RAG·MCP로 자동화를 설계합니다.

HOW I WORK

함께 일하기 전에 궁금할 것들

디자인의 의도를 손실 없이 코드로 옮기는 일, 그리고 그 코드 위에 AI 자동화를 얹는 일입니다. 화면 품질(접근성·마크업)과 시스템 사고(데이터·배포)를 동시에 신경 쓰는 사람이 드문데, 저는 두 세계의 언어를 모두 씁니다.

결과물을 먼저 보여드리고, 그 위에서 구조화된 질문으로 방향을 좁히는 방식을 선호합니다. 막연한 논의보다 동작하는 프로토타입과 명확한 근거가 담긴 선택지를 제시해 의사결정을 빠르게 만듭니다.

유행이 아니라 유지보수성과 확장성을 기준으로 고릅니다. 변수 기반 CSS 설계, 명확한 API 경계, 그리고 보안을 처음부터 고려하는(secure-by-design) 습관을 중요하게 봅니다.
