디자인 → 퍼블리싱 → AI,
경계를 넘을 때마다 직접 만들었습니다

UX/UI 디자이너로 시작해 사용자의 감정선을 읽는 시각 언어를 익혔고, 그 감각을 직접 구현하기 위해 퍼블리싱을 배웠습니다. 기업 홈페이지·병원·앱 프로젝트에서 디자인과 마크업을 함께 맡으며 디자인 의도와 실제 구현의 간극을 0에 가깝게 만드는 일을 해왔습니다.

지금은 전자계약 SaaS SignOn에서 브랜드 디자인 시스템 구축, JSP 레거시 환경의 프론트엔드, 콘텐츠 마케팅까지 풀사이클을 담당하면서 — 동시에 LangGraph 기반 계약서 분석 에이전트(LegalLens-K)를 설계·개발하고, 한국 정부 디자인 시스템(KRDS) 74개 컴포넌트를 Claude Code 스킬 패키지로 직접 제작했습니다.

AI를 "쓰는 사람"에서 멈추지 않고, AI가 일하는 파이프라인과 도구 자체를 만드는 사람으로 이동하고 있습니다.

두 개의 트랙, 하나의 결과물

퍼블리싱 트랙이 화면의 신뢰를 만들고, AI 트랙이 그 화면 뒤의 자동화를 만듭니다. 두 역량이 한 사람 안에 있을 때 기획–디자인–구현–AI 통합의 핸드오프 비용이 사라집니다.

TRACK 01 — PUBLISHING

웹 표준 퍼블리싱 & 디자인 시스템

접근성과 유지보수성을 기본값으로 하는 클린 마크업.

  • 시맨틱 마크업 · WCAG 접근성 — KRDS(정부 디자인 시스템) 기준 실무 적용
  • CSS 아키텍처 — 커스텀 프로퍼티 토큰 설계, 인라인 스타일 통합·중복 제거 리팩토링
  • 반응형 · 크로스브라우징 — 모바일 퍼스트, 디바이스별 최적화
  • JSP 레거시 환경 — 운영 중인 서비스의 제약 안에서 안전하게 개선
  • 인터랙션 구현 — 순수 CSS 토글, IntersectionObserver, React 컴포넌트
TRACK 02 — AI AGENT

AI 에이전트 설계 & 통합

LLM을 제품 기능으로 바꾸는 파이프라인 설계.

  • LangGraph 멀티스텝 에이전트 — 상태 그래프 기반 분석→판단→실행 파이프라인
  • RAG 설계 — Qdrant 벡터 DB, 공정위 표준계약서 기반 검색 증강
  • Claude Code 생태계 — ADK 5계층(CLAUDE.md/Skills/Hooks/Subagents/Plugins), 커스텀 스킬 패키지 제작
  • FastAPI 백엔드 — PII 마스킹, JWT 인증 등 보안 설계 포함 API 구축
  • 생성 AI 운용 — Kling/Veo/ComfyUI 영상, Gemini API 자동화, 프롬프트 체계 설계
